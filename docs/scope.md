# النطاق والافتراضات

المرجع الكامل: requirements.ar.md. المنتج HR Platform، منشأة واحدة بقاعدة مستقلة لكل عميل، فروع وأقسام داخل المنشأة. ليس SaaS متعدد العملاء. بدء التشغيل Windows/SQL Server 2022، مع تطوير واختبار على Linux.

المرحلة الأولى: هوية Cookies، CSRF، أدوار وصلاحيات، إعداد المنشأة والفروع والأقسام والوظائف، ملفات موظفين وربط المستخدم والمدير، بيانات مالية مقيدة، مرفقات خاصة، استيراد Excel بمعاينة، سجل تدقيق، واجهة عربية RTL متجاوبة وتأسيس الإنجليزية.

المراحل اللاحقة محفوظة في roadmap.md وتشمل الحضور والإجازات والموافقات والرواتب والأجهزة والأداء. لا يمثل إكمال التأسيس اكتمال المنتج أو جاهزيته للبيع.

اعتمد المستخدم HRPlatform_Dev على KHALID-OSMAN بمصادقة Windows، لكن لا توجد وصلة SQL من السحابة أو بيانات جهاز ZKTeco. لا تنشأ قاعدة على خادم العميل قبل موافقة اسمها واتصالها. SQLite مسموح في الاختبارات المعزولة فقط ولا يثبت توافق SQL Server. لا تضاف نسب نظامية غير متحققة.

أُضيفت دفعة الحضور في 2026-10-18: شفتات وجداول يومية وعطلات وحركات خام واستيراد وحساب مشتق وتصحيحات باعتماد وتسجيل بوابة اختياري. التفصيل والحدود في attendance.md. الإضافي المعتمد والإجازات والرواتب والأجهزة تبقى مراحل تالية.
