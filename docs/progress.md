# التقدم

أُنشئ المشروع من المستودع الفارغ. أساس المرحلة الأولى منفذ وقابل للبناء والتشغيل والاختبار ببيانات اصطناعية معزولة؛ قبول المرحلة على SQL Server الفعلي ما زال معلقًا. ليس المنتج جاهزًا للبيع.

## المنجز

- طبقات Domain/Application/Infrastructure/API وReact، .NET 10/EF Core SQL Server/Identity، ملفات قفل وترحيل أولي وSQL مولد.
- Cookies وCSRF، خمسة أدوار بصلاحيات خادم، نطاق الموظف الذاتي والمدير المباشر، تغيير كلمة المرور وإبطال الجلسات، قفل محاولات الدخول، حماية آخر مدير نظام وتغيير الأدوار وتعطيل الحساب من API.
- إعداد منشأة ومنطقة زمنية، إضافة الفروع والأقسام والوظائف وتعديل أسمائها مع كشف التزامن؛ ملفات موظفين وبحث وفلاتر وترقيم من الخادم، مدير مباشر وتفرد الرقم وربط الحساب.
- بيانات راتب وبنك وIBAN منفصلة بصلاحيات Administrator/Payroll؛ decimal ومدخلات نصية دقيقة ورفض الكسور الزائدة. هذا سجل بيانات حالي فقط، وليس تاريخ تعويضات أو محرك رواتب.
- مرفقات خارج wwwroot وتنزيل مخول وفحص الحجم والنوع، استيراد Excel بقالب ومعاينة وتحقق خادم متجدد وحفظ ذري، سجل تدقيق مع التغييرات.
- واجهة عربية RTL للعمليات المذكورة، وأساس ترجمة إنجليزية، وأساس PWA آمن من كاش البيانات الحساسة.
- مضيف اختبار مستقل ببيانات اصطناعية، تعليمات Windows والنشر والنسخ والاستعادة، حصر تراخيص، وسكربت إعداد سحابي قابل للتكرار.

## التحقق

22 اختبار خادم و7 اختبارات واجهة و7 فحوص متصفح ناجحة في البيئة السحابية. البناء المقفل وRelease publish وفحص اتساق النموذج نجحت؛ لا advisories معلنة في فحص الحزم الحالي. التفاصيل والحدود في validation.md.

أبلغ المستخدم عن نجاح الاختبارات الـ21 الأصلية على Windows ثم فشل تنظيف ملف SQLite. صُحح إعداد اتصال الاختبار لتعطيل pooling وأضيف اختبار إغلاق/حذف (22 حالة ناجحة على Linux). أكد المستخدم نجاح الاختبارات الـ22 على Windows، ثم نجاح اختبارات الواجهة الـ7 وبنائها. عولج كذلك تحذير ترويسات antiforgery دون تعطيل حماية الكاش.

## العائق والخطوة التالية

أكد المستخدم أن SQL Server على جهازه وقدم اسم الخادم وطريقة Windows Authentication. اعتمد المستخدم قاعدة HRPlatform_Dev. الاتصال من السحابة غير متاح، ومحاولة الترحيل على جهازه توقفت قبل إنشاء القاعدة بسبب سلسلة شهادة SQL غير الموثوقة. لا قاعدة عميل أُنشئت أو عُدلت. اتبع windows-setup.md محليًا بعد تحديد الهدف الآمن لتطبيق الترحيلات واختبار القبول؛ لا تتجاوز حارس --migrate لقاعدة موجودة.

## ما بقي من النطاق

سياسات مؤسسة مفصلة وأدوار/صلاحيات مخصصة تتجاوز الأدوار الخمسة الحالية؛ بيانات هوية شخصية حساسة وتاريخ راتب بعقود سريان؛ ترجمة كاملة؛ ثم جميع مراحل الحضور والإجازات والطلبات والموافقات والرواتب والأجهزة والتحميل وفق roadmap.md. اختبارات التزامن الخاصة بالأرصدة والرواتب لا تنطبق بعد لعدم تنفيذ الوحدات.

نجحت اختبارات الخادم والواجهة وبناؤهما على Windows وفق نتائج المستخدم. ترحيل SQL Server الفعلي محجوب بشهادة الاتصال، والنسخ والاستعادة والجهاز الفعلي والأداء والقواعد السعودية لم تختبر. لا معاينات وهمية لهذه الوحدات أو ادعاء تكامل أو امتثال. المستودع المعتمد لتسليم الشيفرة هو khalidmudawi5-dev/HR-System على فرع main، بموافقة المستخدم الصريحة على الرفع. إعداد البيئة السحابية مسودة مستقلة عن نشر التطبيق لدى العميل.

إعداد شهادة تطوير محلية مقترح في docs/local-sql-certificate.md، مع أداة وضعها الافتراضي قراءة فقط. لم تثبت شهادة أو تربط أو تعاد خدمة SQL بعد؛ يلزم قبول أثر إعادة التشغيل على البرامج الأخرى قبل الإجراء.
