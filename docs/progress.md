# التقدم

أُنشئ المشروع من المستودع الفارغ. أساس المرحلة الأولى منفذ وقابل للبناء والتشغيل والاختبار. أكد المستخدم نجاح الترحيل محليًا ثم تسجيل الدخول على Windows؛ قبول المرحلة الكامل على SQL Server الفعلي ما زال مطلوبًا. ليس المنتج جاهزًا للبيع.

## المنجز

- طبقات Domain/Application/Infrastructure/API وReact، .NET 10 وEF Core SQL Server وIdentity، ملفات قفل وترحيل أولي وSQL مولد.
- Cookies وCSRF، خمسة أدوار بصلاحيات خادم، نطاق الموظف الذاتي والمدير المباشر، تغيير كلمة المرور وإبطال الجلسات، قفل محاولات الدخول، وحماية آخر مدير نظام.
- منشأة ومنطقة زمنية، فروع وأقسام ووظائف مع كشف التزامن؛ ملفات موظفين وبحث وفلاتر وترقيم من الخادم، مدير مباشر وتفرد الرقم وربط الحساب.
- بيانات راتب وبنك وIBAN منفصلة بصلاحيات Administrator/Payroll؛ decimal ورفض الكسور الزائدة. هذا سجل بيانات حالي، وليس محرك رواتب أو تاريخ تعويضات.
- مرفقات خارج wwwroot وتنزيل مخول وفحص الحجم والنوع، استيراد Excel بمعاينة وتحقق خادم وحفظ ذري، وسجل تدقيق.
- واجهة عربية RTL، قاموس أساس إنجليزي، وأساس PWA يمنع تخزين بيانات الحسابات في الكاش.
- مضيف اختبار مستقل ببيانات اصطناعية، تعليمات Windows والنشر والنسخ والاستعادة وحصر تراخيص وسكربت إعداد سحابي.

## تحسين تجربة الاستخدام — 2026-10-15

- تصميم جديد لشاشة الدخول ومساحة العمل، خط IBM Plex Sans Arabic محلي بترخيص OFL، أيقونات SVG أصلية، وتنقل جانبي مناسب للجوال.
- لوحة متابعة بأعداد فعلية حسب صلاحية الحساب: حالات الموظفين والمنضمون في الشهر حتى يوم المنشأة، توزيع الفروع، إعداد المنشأة، وآخر النشاط للمدير فقط. الموظف يرى ملفه، والمدير فريقه المباشر، وحساب المالية لا يحصل على إحصاءات دليل الموظفين.
- دليل الموظفين يعرض الوظيفة والقسم والفرع، ويدعم البحث والحالة والفرع والقسم والترتيب من الخادم؛ بطاقات للجوال وملف موظف منظم بالبيانات والمرفقات المسموحة.
- روابط داخلية تحفظ الصفحة والملف بعد التحديث، حماية من الإغلاق العرضي للملف المعدّل، حالات تحميل وخطأ وفراغ، رسائل نجاح واضحة، وتركيز لوحة المفاتيح في النوافذ والقائمة.
- أداة تحديث محلي من أرشيف ثابت مع SHA256 ونسخة احتياطية للشيفرة. تستثني إعدادات الاتصال والأسرار و.local والمرفقات والقواعد وwwwroot؛ البناء الاختياري يختبر ثم يحدث الواجهة المولدة. لا ترحيل ولا إعادة إنشاء حسابات ولا تغيير شهادة أو خدمة SQL في هذا التحديث.

## التحقق

30 حالة خادم و12 حالة واجهة و9 فحوص متصفح ناجحة في البيئة السحابية. نجحت 6 فحوص لأداة التحديث بملفات مؤقتة، وفحص اتساق نموذج EF والنشر Release. التفاصيل والحدود في validation.md. صور معاينة ببيانات اصطناعية في ui-refresh.md.

أكد المستخدم سابقًا نجاح 22 اختبار خادم على Windows بعد إصلاح تنظيف SQLite، ونجاح 7 اختبارات الواجهة والبناء. أرسل نتيجة نجاح تجهيز شهادة تطوير SQL، وتبع ذلك تأكيد نجاح الترحيل ثم تسجيل الدخول. هذه نتائج محلية أبلغ بها المستخدم؛ البيئة السحابية لم تتصل بقاعدة جهازه.

## الخطوة التالية وما بقي

تثبيت تحديث الواجهة على نسخة Windows الحالية ثم إكمال تدفق قبول SQL Server: العمليات الفعلية والصلاحيات والتزامن، إعادة التشغيل واستمرار البيانات، والنسخ والاستعادة إلى قاعدة اختبار معتمدة. التحديث الحالي لا يغير مخطط البيانات ولا يتطلب --migrate أو --bootstrap.

ما زالت مراحل الحضور والجداول والإجازات والطلبات والموافقات والرواتب والأجهزة واختبارات التحميل مطلوبة وفق roadmap.md، وكذلك سياسات المؤسسة المفصلة وتاريخ الراتب والترجمة الإنجليزية الكاملة. لا تعرض الواجهة أرقام حضور أو رواتب غير منفذة.

المستودع المعتمد لتسليم الشيفرة هو khalidmudawi5-dev/HR-System على فرع main بموافقة المستخدم على الرفع. إعداد البيئة السحابية مستقل عن نشر التطبيق لدى العميل.

متابعة تثبيت التحديث على Windows: توقف تنزيل التحديث عند تحميل مكتبة ZIP باستخدام Assembly.Load باسم مختصر، قبل نسخ الشيفرة. صُححت الأداة وفحوصها لاستخدام Add-Type، وأعيدت فحوص حماية الملفات الستة بنجاح على Linux، وفُحص توافر واجهات ZIP في مراجع .NET Framework 4.8. إعادة تشغيل الأداة المصححة على جهاز المستخدم ما زالت مطلوبة للتحقق من التثبيت المحلي.
