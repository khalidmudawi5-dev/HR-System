# مراحل التنفيذ ومعايير القبول

1. التأسيس: مصادقة وصلاحيات ونطاق بيانات، منشأة وهيكل وموظفون، استيراد بمعاينة ومرفقات وتدقيق، migrations، واجهة عربية، اختبارات رفض الوصول والتعارض. يلزم كذلك اختبار migration والتدفق على SQL Server الفعلي.
2. الحضور: جداول ثابتة ومتغيرة وليلي وراحة وسماح؛ خام غير قابل للتعديل، إعادة حساب، تصحيح معتمد، استيراد متكرر آمن. قبول: شفت ليلي ونقص بصمة وتكرار واستثناءات؛ الوقت المعتمد من الخادم.
3. الإجازات والطلبات: سياسات بتاريخ سريان ودفتر أرصدة وحجز، حالات وإلغاء، مسارات وتفويض، طلب تغطية مستقل عن التكليف، بوابات الموظف والمدير. قبول: تعارض وتزامن ومنع اعتماد الذات وآثار الإلغاء.
4. الرواتب: مدخلات بتاريخ سريان، decimal وتقريب مصرح، مراجعة واعتماد وإقفال ولقطات غير قابلة للتغير، كشوف خاصة. قبول: تدفق إجازة إلى راتب وثبات المسير المقفل. القواعد النظامية تتطلب تحققًا رسميًا.
5. الأجهزة والتشغيل: عقد موصلات ومحاكي واستيراد، مزامنة واستكمال وتكرار آمن؛ اختبار جهاز فعلي منفصل. تحميل 1,000 موظف ودفعات متزامنة مع مواصفات ونتائج. نشر Windows ونسخ واستعادة مجربة ومراجعة أمن وحسابات قبل البيع.

## حالة دفعة 2026-10-18

الجزء التشغيلي للحضور منفذ: تعريف شفت ثابت، توزيع جداول يومية قابلة للتغيير، ليلي وراحة وعطلات واستراحة وسماح، خام غير قابل للتعديل من التطبيق، استيراد Excel متكرر آمن، حساب مشتق عند القراءة، تصحيح معتمد يمنع اعتماد الذات، وبوابة تسجيل اختيارية بوقت الخادم. التكليفات والإضافي المعتمد والربط بالإجازات والرواتب والموقع والأجهزة ما زالت ضمن المراحل اللاحقة. لا تعتبر هذه الدفعة اكتمال جميع متطلبات المرحلة الثانية أو المنتج.
